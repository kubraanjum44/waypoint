# Waypoint

A full-stack MERN platform for discovering, creating, and sharing places.

## Planned Features

- Browse place listings without logging in
- Register and log in using JWT authentication
- Create, view, update, and delete listings
- Protect listings so only their owners can modify them
- Interactive maps using Leaflet and OpenStreetMap
- Search, filters, favorites, and shareable links
- Responsive design for desktop and mobile

## Tech Stack

- MongoDB and Mongoose
- Express.js and Node.js
- React.js with Vite
- JWT authentication and password hashing
- Leaflet and OpenStreetMap

## Project Status

Initial setup. Features will be implemented and documented as development progresses.
